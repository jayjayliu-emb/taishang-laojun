# 太上老君·AI炼丹炉（taishang-laojun）

> **别人的爆款，都是你炼丹的原料。太上老君AI炼丹炉——把你的选题喂进去，炼出能火的视频。**

> **炉子教的是思路，不是模板。** 每条选题、钩子、标题，都说得清"为什么是它"——你和 AI 都清楚每个判断的因：知道什么时候抄、什么时候不抄、为什么用它。

「太上老君·AI炼丹炉」是一套教 AI 帮内容创作者做事的技能包（Skills）。把创作者"柳爷"的真实爆款复盘炼成可执行的判断标准，任何支持 Skills 的智能体安装后，在对话框里直接就能用。

## 它能做什么

**先认识你，再帮你炼丹。** 第一步不是急着出选题，而是先访谈你——一场聊天，同时办三件事：

1. **了解你**：你是谁（行业/账号定位）、给谁看（目标客户）、你在哪一步（有对标？有选题？有稿？拍完？剪完？还是要变现？）
2. **炼底味**：从你讲的真实故事里提炼你的"说话DNA"（句式/用词/叙事/情绪/连接），生成专属于你的《底味手册》——**每个人的底味手册都不同，必须现场炼**，写文案前先加载它，出来的话才像你说的
3. **挖素材**：你讲出的故事、场景、案例、观点，全记下来——这就是选题/开头/标题/拍摄的原料

访谈不是问卷。炉子用"访谈框架"（起手式 → 顺着你的话追问 → 引向故事），不会拿同一份问题清单问每个人——好的访谈者有一套框架，不是一份问卷。

不了解使用者就出选题、出标题，等于闭眼炼丹——所以炉子会先访谈你，再按需输出能直接开拍的东西：

- **选题 ×3**：给谁看、为什么能拍、标题示例（不是十个用不上的泛选题）
- **为什么能拍**：每个选题说清人群/认知/钩子/可验证/低门槛怎么对上（不许只换行业名）
- **开头改写稿**：前 2 秒钩子原话 + 第二画面证据链 + 为什么用这个开头（匹配点+什么时候不合适）
- **标题 ×3**：按"跟我有关"三源出，每条附理由 + 为什么用这个标题（具体是哪件事）
- **拍摄清单**：场景/画面/动作
- **验证标注**：已验证 vs 待验证（不虚构、不吹牛）

输入可以是：一条对标的视频/逐字稿、一个场景、一个热点、或一句"我想拍点什么"。

**去AI味是内置的。** 炉子自带一套去AI味规则库——24种AI写作痕迹逐条对照（内容/语言/风格/交流四大类）、五步修复流程、真实个性注入原则。写作规则是"先诊断后修改，命中才改"：逐句挑出像AI的地方，说清命中哪条，再动手。识别框架借鉴自开源项目 humanizer-zh（MIT License），详见 [docs/deai-rulebook.md](docs/deai-rulebook.md) 与 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## 核心方法（来自真实爆款复盘）

| 模块 | 名称 | 一句话 |
|---|---|---|
| 选材 | 掂量三关 | 复读测试（口吻像不像我）→ 客户测试（目标客户会不会点头）→ 替换测试（形式换成我的能不能做到） |
| 看火 | 选题五要素 | 人群广 × 认知基础 × 心理钩子 × 事实可验证 × 低门槛 |
| 开炉 | 五段式骨架 | 钩子 → 证据 → 承诺 → 条件 → 指令 |
| 开炉 | 勾证衔接 | 开头负责勾，第二个画面负责证，勾和证之间不能断 |
| 收丹 | 跟我有关三源 | 认人（名人）/ 认事（共识）/ 认心（观众潜意识里藏着的想法） |
| 回炉 | 借观点不借脉络 | 观点相同没问题，流程脉络大差不差会被扒 |
| 成丹 | 合规承接 | GitHub 开源/公开产品承接，禁私聊引流 |
| 全局 | 教因不教果 | 每个成品必须说清"为什么用这个"——匹配选题/调性/主旨，只给果不给因=没理解思路 |

## 怎么安装

| 智能体 | 安装方式 |
|---|---|
| 豆包 / 豆包工作 | 把 `skills/` 目录复制到技能目录即可（零适配） |
| Claude Code | 复制 `skills/` + 配置 `.claude-plugin/marketplace.json` |
| Codex | 复制 `skills/` + `AGENTS.md` 入口 |
| Grok | 复制 `skills/`（Grok Build 支持） |
| 生成 Bot（豆包 Bot / Coze 等） | 用 `bot-prompt/liuye-bot-prompt.md` 直接粘贴为 system prompt |

详细见 [docs/install-guide.md](docs/install-guide.md)。

## 项目背景

- 创作者：柳爷（抖音"柳爷不迷糊"，AI 内容创作者/视频操盘手）
- 流量背书：做过医学科普、大健康、个人日常等多类账号，单条视频最高数百万播放（500万-800万级），全网累计播放量数千万——这些是方法论的"验丹炉"，每条配方都在真实流量里验证过
- 方法来源：真实爆款复盘——把多年多账号的爆款经验炼成六模块判断标准，不是编出来的方法论
- 结构借鉴：dbskill（dontbesilent2025）的开源 Skills 设计；方法内容全部为柳爷原创复盘
