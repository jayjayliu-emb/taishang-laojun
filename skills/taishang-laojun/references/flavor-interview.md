# 底味访谈：把用户自己说不出来的东西引出来

柳爷说过：“我最大的问题就是没办法自己总结出来我自己的东西。但我经常跟别人闲聊的时候，会说出来很多很惊人的东西。”大多数用户都是这样。所以访谈的目的不是收集答案，是**引**：引出一件具体的事，然后由你替用户总结出用户自己没意识到的东西，再还给用户确认。

柳爷也给过反面评价：“你这个问题问得太初级了吧。”问卷式的问题（你的定位是什么、目标受众是谁、你想做什么类型的内容）就是初级问题。用户要是答得出这些，就不需要你了。

## 一场访谈同时拿到三样东西

用户讲一件具体的事，你同时拿到：

| 拿到什么 | 用在哪 |
|---|---|
| 事实：行业、做过的事、手里的资源、能拍的场景 | 选题、证据、场景 |
| 底味：句式、用词、口头禅、讲事的顺序、情绪的尺度 | 写稿时“像不像本人” |
| 素材：故事、观点、判断、踩过的坑 | 选题、开头、标题 |

所以不要分三轮问三类问题，问一件事就够了。

## 怎么开口

第一个问题要具体、低门槛、对方一定答得上来：
- 从最近的事切入：“这周干的最费劲的一件事是什么？”
- 从刚说过的话切入：“你刚提到那个客户，后来怎么样了？”
- 从刷到的东西切入：“最近刷到哪条视频，你是一口气看完的？”

不要问“你想做什么内容”“你擅长什么”。

## 高阶问题：问决定，不问定义

初级问题问的是定义（你是谁、你的观众是谁）。好问题问的是**一个具体的决定**，因为判断方式藏在决定里：

- “那次你为什么选在那里拍，而不是在家拍？”
- “别人推荐了一堆，你最后只留了哪两个？为什么删掉其他的？”
- “你当时本来想吸引谁？最后来的是谁？”
- “这件事你跟朋友讲的时候，第一句会怎么说？”
- “你做的时候最怕观众怎么想你？”

## 顺着对方的话追

| 对方说了什么 | 追什么 | 为什么 |
|---|---|---|
| 一个结论（“做自媒体太累了”） | “最累的是哪一回？” | 结论是观点，故事在细节里 |
| 一件事（“上次那条视频火了”） | “怎么一步步起来的？中间卡过吗？” | 过程暴露叙事逻辑和决策 |
| 一个过程 | “当时心里怎么想的？” | 心理暴露情绪方式和真实动机 |
| 别人的事 | “那你自己碰到会怎么办？” | 引出对方自己的判断 |
| 很书面的话（“我认为应该赋能”） | “这话发微信给朋友，你会怎么说？” | 找到本人舒服的表达 |
| 很短、很干 | “举个例子？” | 细节里有语言习惯 |

规则：每次只问一个；先复述对方刚说的一个细节再问，像聊天不像审问；对方不想说的不逼，换个方向。

## 往哪里引

看当下最缺什么，往这几个方向带：
1. 最得意或最尴尬的事 → 自信与自嘲的尺度；
2. 当时心里的小算盘 → 真实动机；
3. 最烦的东西 → 底味的反面，写稿时要避开的表达；
4. 最近刷到停下来的东西 → 选题线索；
5. 跟朋友安利一样东西时怎么说 → 内容转化的语气。

## 替用户总结（这是你的活）

聊出一两件事后，不要等用户总结。由你来说：

- “从你刚才讲的这两件事看，你的判断方式是……（引用用户原话）”
- “你讲事的习惯是先说结果再倒回去讲过程。”
- “这里面最能拍的是……，因为观众会……”

每个发现都带一句用户的原话做证据，然后请用户确认或纠正。拿不准的标“待验证”，下次写稿时再校准。只从原话提炼，不脑补风格；转写错字和语气词不能直接当个人风格。

## 访谈老板、客户（替别人做号时）

访谈对象换成老板，问法一样，重点找四样东西：老板身上让人向往的生活、生活中发生的具体事件、事件里露出来的判断力、观众看完会去找他的理由。冷门产品本身往往不是主角。

## 从经历走到一条可拍的方向

不需要成功案例。工作中的一次调整、一次失败、一个日常观察都可以。顺着最近的一件事，按缺口了解：当时做了什么、为什么这样做、卡在哪里、改了什么、实际发生了什么。不按顺序问完，已经回答的直接用，不预设结果是好的。

够判断了就交付：这件事里已知的事实、用户的判断、可能对谁有用、能拍到或讲清的证据、影响选题的缺口。然后按[看火](../../tslj-idea/SKILL.md)给少量方向。具体经历不自动等于好选题，要说明观众为什么值得看；价值或证据不够，就说原因，给一个补材料的方向。

## 什么时候停

- 拿到一条可拍方向需要的东西就停，先做一个小交付，再用反馈校准。通常三到五轮，材料够了就停。
- 用户只要改标题、改开头，不启动完整访谈。
- 用户不想聊，就用现有材料给范围明确的建议，说清还不是量身定制的版本。

## 底味手册（用户想要时才整理）

用户需要一份完整手册时，整理在当前对话里：

```markdown
# {名字} 的底味手册（现场炼，非通用）

## 身份与观众
- 做什么的 / 给谁看 / 现在想完成什么（都来自访谈）

## 说话的样子（每项带一句原话）
- 句式 / 用词 / 讲事顺序 / 情绪尺度 / 怎么转折

## 不要的表达（用户亲口说烦的）

## 素材库（聊出来的故事、场景、观点、判断）

## 最像本人的 3–5 句原话
```

## 边界

- 收集的是语言样本和创作素材，不是隐私档案。不问收入、联系方式、私生活细节。
- 手册和素材只在当前对话使用，不进公共仓库。单次删一个词不升级成永久禁令；用户明确表达或多次稳定反馈后，再更新长期偏好。
