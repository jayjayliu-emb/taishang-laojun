# 开炉：开头与结构

## 先确定这条要表达什么

读取主题、目标观众、实际素材和拍摄条件。先用一句话确定观众看完应明白什么。题目没定时先解决方向，不随意套爆款开头。

**场景倒逼**：已有海边、工厂、机场等场景时，场景是工具，先问想通过它表达什么，再匹配自己的经历与参考观点。没有稀缺场景也能用普通生活动作开拍；背景本身不能证明成功、收入或身份。

## 核心方法

- **有限时间的信息密度**：开头尽快让人理解且产生兴趣。付出、反差、情绪可组合，但不是硬塞2–3条信息。删掉不服务核心意思的内容；一两件关键事说透胜过罗列所有工具。
- **勾证衔接**：第一句提出的期待，紧接着用真实事件、动作、演示或证据画面接住；不得空喊夸张话。没视频画面也可用一个具体事实推进，不强制添无关镜头。
- **案例衬托内核**：与其自称厉害，用具体行动和结果让观众理解判断。没有经历不编，可以做可检查的演示并如实标明。证据也不只有结果——展示你查了哪些别人想不到的维度、怎么拆解问题，思考过程的深度本身就是能力证明，且比结论更难被质疑。
- **认心先发**：开头把观众心里已有、没说出来的话先替他说出来——包括对你的防御（"又要卖课了吧"）。防御在形成之前被说出，比事后解释便宜。只用于真实普遍存在的心理，不虚构观众心理。
- **反共识开场**：当确实有被忽视的缺点或代价时可用；不是为了权威感硬唱反调。
- **标题、口播、画面分工**：口播承载不下的背景或总结可以交给标题，画面负责展示，避免三处同时堆重复信息。

## 选择结构而非统一套用

教学/分享资源时，可采用柳爷的五段式：**钩子 → 证据 → 承诺 → 条件 → 指令**。承诺必须可兑现，条件包含真实使用门槛，指令服务用户目的；不是每条都要领取、评论或进群。条件的正确做法是诚实设计疑问：让观众"简单起步"，如实预告真实门槛会在哪一步出现、卡住时从哪里提问——提问入口就是承接口；不靠隐瞒门槛制造提问。

记录/故事可用事件 → 行动 → 变化；专业答疑可用问题 → 解释/演示 → 结论。这些是候选，不是新硬模板。依据素材选结构，简短说明为什么匹配。若中段需要演示，保留关键操作和结果对照，不只写开头结尾。

时长由信息与现场行动决定：十几秒讲清不拉长，有必要过程也不强缩。面对已拍素材，按实际可读片段给取舍和顺序，未读取素材不编时间戳，不声称完成剪辑。

## 输出与边界

按请求给：1–2个开头原话、紧接的证据/画面、必要的中段推进与收尾、可执行镜头建议，以及为什么选它/什么条件变化要换。只要改开头就不强交全套。

本模块负责结构与拍法；**完整逐字稿由回炉负责**。如用户要整稿，向总入口返回可用结构与缺口，不让用户在模块之间重来。

写出的句子使用已有个人表达样本；需要口吻修订时读取[去AI味规则](../taishang-laojun/references/deai-rulebook.md)。数字与经历只用明确材料，不为制造证据而补写。
