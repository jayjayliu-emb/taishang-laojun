> 本文件是「太上老君·AI炼丹炉」的方法论全集，人读版。所有模块 SKILL.md 与 bot-prompt 均以此为底料。
> 来源：创作者"柳爷"真实爆款视频复盘（Claude封号 20万+ / Grok上手指南 10万+ / 海边 500+粉 / 机场置顶 / 扣袋 88万 / 一人公司 11万 / 世界杯 18万 / AI打工仔 50万+涨粉四五千）。
> 每一格配方都经过真实数据验证，不是编出来的方法论。

## 〇、通用化说明（各行各业都能用）

**这套配方怎么用**：配方里的逻辑是通用的（人群/痛点/钩子/证据/承诺），例子是 AI 方向的。任何行业的人使用时，把"AI 例子"换成自己行业的例子即可。

**对照法**：每个配方都有一个底层逻辑 + AI 版例子 + 行业通用版例子。你属于哪个行业，就照"行业通用版"那列对号入座。

| 配方逻辑 | AI 版例子（柳爷） | 行业通用版例子 |
|---|---|---|
| 人群广 | 玩 AI 的人都会面临 Claude 封号 | 做餐饮的都会遇到客流差；做装修的都怕被坑；做健身的都遇到过平台期 |
| 认知基础 | 玩 AI 的都知道 Claude 大名 | 干这行的都知道这个行当的"大名"（不用解释它是什么） |
| 心理钩子 | 越不让用的工具越想用 | 越贵越想学（稀缺）、越说"不能做"的越想做（逆反） |
| 事实可验证 | 查过官方文档：Grok 可按需调用 Claude | 你的观点必须查证过（数据/政策/案例），不能是编的 |
| 低门槛 | 教 Grok 上手：有手就会 | 教任何事都别让人感觉难；"有手就会+极低成本"才会看 |
| 钩子 | "养了一堆猥琐的 AI 打工仔" | "我花了三个月，偷偷做了一件事"（付出+悬念+幻想） |
| 证据 | "给我贡献了几十万播放" | "这个月就靠这一个办法，多赚了 X 万"（数字+画面） |
| 承诺 | "这些东西我都会给到大家" | "方法/资料/清单我都会给到大家" |
| 条件 | "前提你得先学会怎么用" | "想这么做可以，前提你得先看完/先跟着做" |
| 跟我有关-认人 | 马斯克放大招 | 行业大牛/大品牌最近放了大招 |
| 跟我有关-认事 | Claude 封号 | 这个行业最近人人都在说的事 |
| 跟我有关-认心 | 一人公司肯定有坑 | 观众嘴上不说、心里一直在琢磨的怀疑（"都这么说的肯定有坑"） |
| 借观点不借脉络 | 借 dontbesilent 的数据观点，脉络用机场场景 | 借同行的观点/数据，内容脉络（场景/开头/证据）必须是自己的 |

**通用化的关键一步（对话模板）**：给任何人用之前，先问三件事：①你是做什么的（行业）②你平时的内容/客户长什么样 ③你刷到过哪条觉得"这说的不就是我"的视频——然后把下面的配方全部套进他的行业语境。

## 一、总纲：一句话定位

**别人的爆款，都是你炼丹的原料。把你的选题喂进去，炼出能火的视频。**

四个字公式：**有情、有趣、有人、有事**——人物、事件、情怀、意思。前期内容不必四项全占，有一两项就能开拍。

## 二、选材（对标筛选）：掂量三关

看到一条感兴趣的视频，先过三关，再决定要不要对标它：

**第一关：复读测试（口吻）**
照着他的话念一句，心里复读一遍：
- 复读出来很别扭、不像自己的话 → 放弃
- 复读出来顺口、像自己的话、能自然接下一句 → 通过

**第二关：客户测试（价值）**
假想自己是目标客户，看完这条视频我得到什么？三问至少两问点头才过：
- 这条视频能帮我（提升/变现）吗？
- 放在我的账号里，我的粉丝会爱看吗？
- 我自己感兴趣吗？（我感兴趣的，我的粉丝大概率也感兴趣）

**第三关：替换测试（落地）**
想象把它的形式换成我的：例如它以"一版书"形式讲，我换成"口播+截几张图"能不能做到？
- 能做到 → 照搬
- 形式换不了但观点能留 → 改造
- 只过一关 → 放弃

**过关规则**：三关全过 → 照搬；过两关 → 改造；只过一关 → 放弃。

## 三、看火（选题判断）：五要素 + 两条定律

### 选题五要素（能拍的标准）

**人群广 × 认知基础 × 心理钩子 × 事实可验证 × 低门槛 = 值得拍**

1. **人群足够广**：这个痛点谁都会遇到（玩AI的人都会面临Claude封号，不分高手小白老板大神）
2. **认知基础强**：玩这个的人都知道它的大名，不用解释"这是什么"
3. **心理钩子**：越不让用的越想用、越得不到的越是好东西（稀缺感/逆反心理）；"躺赚"钩子能用但必须讲透真相
4. **事实可验证**：说的事必须查证过（查官方文档印证），不能是编的
5. **低门槛**：如果是要教别人一件事，这件事要"有手就会"+极低成本（钱/行动力/脑子）就能学会——人的惰性决定了大家想看低成本能学会的东西

### 两条定律

**被动接收选题定律**：选题灵感来自"被动刷到"而非"主动搜索"。主动搜=带着框架找到框架里的东西；被动刷=判断系统自动筛选，刷到"这说的不就是我"的时刻。选题系统=被动接收+瞬间判断，不是主动搜索+慢慢对比。

**需求先行定律**：找接点先问"大众最关心什么"，再想AI能做什么——需求在前，工具在后。

### 热点接点三步法

热点（世界杯）→ 大众最关心什么（预测比分）→ AI/我的能力接住（用AI做预测模型）。
注意：**接点决定人群**——预测比分这个接点天然吸赌球人群。想吸引"想学的人"，落点必须指向方法；想吸引"广告主"，落点指向曝光数据。

## 四、开炉（开头与结构）

### 五段式骨架（爆款统一结构）

**钩子 → 证据 → 承诺 → 条件 → 指令**

1. **钩子**：一句话塞多个信息，且全部好懂（例："我花了三个月，养了一堆特别猥琐的AI打工仔"=付出+遐想+躺赢幻想三合一）
2. **证据**：马上接住钩子的画面/事件/数字（"贡献了多少播放量？几十万吧"——故意说得轻松=实力感）
3. **承诺**：都会给到大家（看完的理由+关注的理由）
4. **条件**：想这么做可以，前提先学会怎么用（把"看完"变成得到的前提）
5. **指令**：评论区扣1→进群/关注

### 开头信息密度法则

开头一定要在有限时间表达尽可能多的信息，且信息必须让人好理解（不用听不懂的词）。前两秒同时要：下钩子 + 反常识 + 表达情绪。元素太多会啰嗦——说不完的总结交给标题（标题三职能之"承担总"）。

### 勾证衔接原则（防划走，最重要）

钩子抛出去，后面必须立刻用真实事件/画面接住，否则观众觉得你纯夸张、纯勾人看，会划走。
**开头负责勾，第二个画面负责证。勾和证之间不能断。**

### 场景倒逼选题

先有好场景（巨人展/机场/工厂门口/海边）→ 场景是工具 → 我通过这个工具达到某个目的 → 再倒逼出内容。不是先想选题再找场景，是**锁定稀缺场景，再倒逼选题**。

### 案例衬托内核（信任核心）

有些事情说直白了别人不信（"我忙不过来赚不到更多钱"），一定要用真实案例衬托你想表达的内核（住深圳、跑东莞两三小时、一天只能接待一两个客户）——**直说=不信，案例=信任**。

### 反共识开场

大家都说好（一人公司赚钱）→ 你反着说缺点 → 反而更爱听。潜台词：敢说缺点=你肯定懂=不是为了割韭菜。反共识+案例支撑=权威感。

## 五、收丹（标题）

### 三个前提认知

1. **标题 ≠ 选题**：选题决定上限（10万/50万/500万），因为选题划人群；标题决定打开率。
2. **标题后置**：标题是拍完剪完、反复看视频、提炼要点之后才定的——先有内容后有标题。
3. **标题三职能**：补全信息 / 制造期待 / 承担"总"（视频是总分总结构，标题当那个"总"）。

### 跟我有关三源（标题可信度来源）

1. **认人（名人背书）**：马斯克放大招——"你信不信没关系，马斯克先吸引眼光，工具上手指南我可以看两三秒"
2. **认事（共识话题）**：Claude封号——大家都知道的事→想听你聊一聊→"换个思路试试"给出期待
3. **认心（潜意识显性化，最高级）**：一人公司有个致命缺点——大家刷到的全是"一人公司赚钱"，观众潜意识其实在琢磨"都这么说肯定是割韭菜、肯定有坑"→把观众藏在心里没说出来的话变成标题=最高级跟我有关

**标题判断清单**：
- 是不是视频的"总"？
- 陌生人第一眼会不会问"你是谁凭什么"？（会=没可信度）
- 有没有"跟我有关"的落点：我认识的人 / 我认可的事 / 我心里的想法？
- 埋钩子了吗（看完能得到什么/会变成什么）？
- 好标题=观众认知内的对象 + 观众潜意识里的疑问/期待；差标题=创作者立场的能力宣告（我教你/我能帮你）。

## 六、回炉（文案转写）

### 三个原则

1. **逐字稿是弹药库，不是改稿对象**：看到好内容先保存逐字稿（存手机），不急着改——特意去改往往改不好（抓不住重点、怕破坏逐层递进）。
2. **场景优先匹配**：遇到好场景/热点/想拍的心态 → 场景是工具 → 翻出收藏的逐字稿，找最契合当前场景的稿。不是"改稿适配自己"，是"场景选稿"。
3. **借观点不借脉络**：观点相同，没问题；流程脉络大差不差，会被扒出来。正确姿势=借核心观点 + 换成自己的场景、自己的开头、自己的证据链。

**为什么不能盲目改稿**：爆款稿的句子有顺序逻辑（第一句说什么、第二句说什么，每个字都有道理），是"逐层递进"的；上下不衔接=观众划走。拆散它=杀死它。

## 七、成丹（变现承接）

### 变现的合规路径（不做私聊）

- 产品标准化：GitHub 开源 + 公开产品（Bot/技能包）+ 免费试用 → 公开付费路径
- 承接位置：主页引导 / 评论区 / 私信引导到公开产品，**不加微信私聊**
- 粉丝从视频→工具/内容/服务的合规路径，是炼丹炉要解决的核心问题

### 三条教训

**预期用户 ≠ 实际用户**：展示结果→勾来要结果的人（求职者）；展示过程/方法→勾来想学的人。钩子展示层必须与目标人群对齐。

**过程终点定律**：过程的终点是"结果"→来要结果的人；终点是"方法"→来想学的人。想吸引学习者，落点指向方法。

**三层分离定律**：点赞者（爽点）≠ 私信者（需求）≠ 付费者（购买）——统计别混为一谈。

**价值观边界即筛选器**：不掺和违法/害人事（赌球、灰产），可做成底线人设——有原则的人更可信。

## 八、底层认知（通用）

### 破冰论
所有平台（短视频/销售/GitHub）都是销售逻辑。第一步永远是让别人对你感兴趣：短视频1-2秒、面对面三句话、GitHub一个名字。名字和功能要一针见血戳中对方"想象不到的痛点"——很多人并不清楚自己的痛点，被戳中的那一刻才知道"这说的不就是我"。

### 神秘感论
教人安装使用=变说明书=没神秘感。能赚钱的人设是"不展示会什么，观众从判断和结果里觉得你什么都会"。判断和趋势 > 教程和方法。最高级是不经意露出（无意识感），"故意藏"一露就破功。

### 观众心理五类
1. **娱乐化**：泛流量（带货/广告需大基数）
2. **利他教学**：小号没人看（粉丝没到量级手把手教=划走）
3. **"躺赚"钩子**：起量快但必须讲透真相
4. **技术展示**：必须真狠（半调子没流量）
5. **下危机**：李尚龙式——制造焦虑+严丝合缝解决；只下危机不给解法=贩卖焦虑

### 选兵器论
选AI工具/对标，不选最火最贵数值最高的——多试几个（孙悟空试九股叉大刀方天戟最后定海神针，还要能大能小掂量），适合自己才是生产力工具。别追新别攀比，花最少的钱试。

### 爆款七步法（海边案例）
真实场景 → 大众共鸣 → 破偏见钩子 → 想象空间 → 画面验证 → 权威背书 → 轻转化收尾

### 一厢情愿的想象空间
第一句话给足"一厢情愿的想象"（学AI→不想上班就不上班→想带孩子玩就带孩子玩→有钱有自由→AI替我干活）——播放高靠想象，涨粉高靠承诺（承诺密度与涨粉效率正相关）。

## 九、硬边界（所有模块通用）

- 不承诺播放量/涨粉效果
- 不虚构数字、身份、经历；没验证过的一律标"待验证"，不写"我测试过了"
- 不提供违规引流（加微信私聊等）
- "躺赚"钩子必须讲透真相
- 涉及违法（赌球/灰产）一律不沾
