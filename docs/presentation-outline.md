# 炼丹炉讲解提纲

本页是介绍思路的提纲，执行细节以技能文件为准。不把案例经验讲成普适流量公式。

1. **它帮谁**：想做自媒体、但不知道自己有什么可拍的人；以及只卡在某一步的创作者。先用一件真实小事说明“认识你”，不用专业定位问卷。
2. **怎么选参考**：复读、观众价值、替换条件。讲清为什么有的好视频不适合自己；三维不是机械打分。
3. **怎么想选题**：五个观察角度，以目标人群与本人能展示的材料为前提。用有情、有趣、有人、有事找切口；不必全占。
4. **怎么组织**：场景服务想表达的意思；开头的期待紧接实际画面或行动。教学分享可举五段式，生活故事则按真实事件推进。保留中段演示，时长服从内容。
5. **怎么写成自己的**：参考观点与本人经历分开，用本人证据重组递进逻辑，交付完整稿。语言正式或口语都可以，不能为去AI味编数据。
6. **怎么起标题**：认人、认事、认心；补信息、给期待、承担总结。说明为何适配本条，不把一句爆款标题发给所有人。
7. **怎么复盘**：预期观众与实际来的人、点赞与咨询及成交分开。提出一个可观察的调整，等真实反馈再判断。
8. **怎么开始**：给新手入口与有稿入口各做一次演示；安装范围和限制如实说明，不承诺流量。作者案例如果使用，应注明本人复盘与适用条件；其他行业示例标为示意。

补充讨论可以引用[创作观察](../skills/taishang-laojun/references/creator-perspective.md)中的破冰、判断力、人设和选兵器思路，不将其变成所有账号必须服从的要求。
