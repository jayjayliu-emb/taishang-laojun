# 炼丹炉讲解提纲

本页是介绍思路的提纲，执行细节以技能文件为准。不把案例经验讲成普适流量公式。

1. **它和别的 AI 有什么不一样**：AI 先下判断，用户来校准；每次落到一件今天能做的事；换个人还成立的建议就是泛货。用柳爷“所有人给我出的方案都不能落地”这句话开场。
2. **炉心七条**：破冰、观众没说出口的话、用事件衬托内核、判断力胜过教程、钩子马上兑现、展示什么吸引什么人、适合自己的才是兵器。每条配一个柳爷的视频讲清“观众此刻在想什么”。
3. **怎么选参考和工具**：孙悟空选兵器；复读、客户、替换三关；对标看条件一致。
4. **怎么想选题**：用世界杯案例走一遍选题决策链，讲清“会招来谁”也是选题的一部分。
5. **怎么开头和组织**：机场的钩子链、AI 打工仔的信息打包和两个理由、Codex 两件事的减法。
6. **怎么写成自己的**：逐字稿弹药库、先有场景再找观点、借观点不借脉络；AI 初稿的改动大多是删。
7. **怎么起标题**：跟我有关（认人、认事、认心），用两个没起来的标题讲陌生人视角。
8. **怎么复盘和变现**：一人公司和世界杯的“预期 vs 实际”，纠偏、顺势、拒绝三条路；合规承接。
9. **怎么开始**：新手入口和有稿入口各演示一次；安装范围和限制如实说明，不承诺流量。
